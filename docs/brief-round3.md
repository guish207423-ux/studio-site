## 任务一：品牌标志（P0，最重要）
设计一个**真正的标志**，不是「圆 + 字」。要求：
- 概念必须来自"屿"（岛屿）或"把设计变成能跑的界面"这件事本身，给出概念说明（2-3 句）
- 纯几何、单色可用、16px 下仍可辨认、可做 favicon
- 给 **3 个方向的方案**，每个含：概念名 / 一句立意 / SVG 规格（viewBox、path 数据或构造描述）/ 缩小到 24px 时的可读性说明
- 禁止：圆形/方形容器里塞一个汉字、通用六边形、渐变拟物、字母组合 monogram（这类正是"太 AI"的来源）
- 参考方向（不强制）：地形等高线、岛屿轮廓、两层平面错位、单个负空间切口

## 任务二：图标系统（P0）
- 每个 section 头部换成 **iconsax-react** 图标（库已在依赖里），给「section → 图标名」映射表
- 状态类形变用 **morphicons**：只用在**图标↔图标**且结构匹配的场合（FAQ 的 chevron 下↔上最合适；汉堡↔X 是 3 线对 2 线，结构不匹配，不要硬用）
- 规格：24×24 网格、`reducedMotion="user"`、stroke 宽度随字号收敛
- 说明为什么这样映射（图标要与内容语义相关，不能凑数）

## 任务三：去卡片化（P1）
现在 about / services / testimonials / partners / cases 等区块大量是「等宽卡片网格」，读起来单调。给改造方案：
- 哪些区块**保留卡片**（理由）
- 哪些改成**其他形态**：交错双栏、编辑式长文、编号列表、横向滚动带、大字排版区、表格
- 每条给：区块 id / 现状 / 目标形态 / 需要的 CSS 结构与断点行为
- 约束：不得引入新的依赖；改动要能用现有 token 完成

## 任务四：文案（P1，官方、专业）
- 逐条给「原文 → 改写」，覆盖 hero / about / services / cases / pricing / contact / footer
- 语气：**官方、专业、克制**。可以自信，但不卖萌、不用感叹号、不用"我们相信"这类抒情句
- 禁用：全谱系/赋能/闭环/一站式/打造/极致/无缝/深耕/助力
- 禁止中英混排（品牌名 YU STUDIO、技术专名除外）
- 每条注明改写理由（一句话）
