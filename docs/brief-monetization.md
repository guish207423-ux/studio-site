# BRIEF：屿作所变现路径研究（只出方案，不改代码）

## 背景
屿作所是一个**两人规模**的数字产品工作室，实际能力边界：品牌视觉 / 界面设计 / 前端实现 / 动效。
官网 `/home/guish/Desktop/Projects/studio-site` 现在有三档报价（¥8,000 起 / ¥28,000 起 / 定制），
特征描述偏笼统（"UI/UX 设计""全栈开发""3 轮修改"），没有产品化、没有复购设计。

用户原话：**「思考如何变现」**。

## 硬约束
1. 只有两个人，不能靠堆人力扩张；方案必须能在 2 人产能内交付
2. 不得虚构客户、案例、收入数字、合作方
3. 不得建议"投流/买量"这类需要预算且不可验证的手段
4. 中文，官方、专业，不写"赋能/闭环/全链路"这类词

## 要回答的问题
1. **卖什么**：把现有能力拆成可单独售卖的产品化服务（每项给：名称 / 交付物 / 周期 / 价格锚点 / 明确不包含什么）。
   至少覆盖：一次性项目、可复购的持续收入、可规模化的资产型收入 三类。
2. **怎么定价**：三档报价的定价逻辑与锚点（为什么是这个数、如何避免被压价、如何应对"太贵了"）。
3. **谁买**：客户画像（行业、规模、触发场景），以及每一类对应的获取渠道。
4. **怎么获客**：在 2 人产能下，最省力的 3 条渠道 + 每条的第一周动作（具体到可执行）。
5. **复购与转介绍**：交付后如何自然产生第二单（维护、巡检、迭代、白标）。
6. **风险**：哪些看起来赚钱但会拖垮两人团队的单子，如何筛掉（给具体筛选问题）。
