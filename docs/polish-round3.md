## 一、品牌标志（P0）

### 概念

屿作所的标志应来自「屿」（岛屿）这一字，或来自「把设计变成能跑的界面」这件事本身——一个标志，不是容器里塞一个字。标志必须是纯几何、单色可用、16px 下仍可辨识、能做 favicon。

### 方案 A ——「等高线岛」

- 概念名：等高线岛
- 一句立意：把「屿」抽象成一组同心的、略偏心的闭合曲线，像地形等高线，暗指「在数字平面上隆起的一块土地」。
- SVG 规格：viewBox `0 0 24 24`，三条闭合 path，外圈半径 10.5、中圈 7、内圈 3.5，每圈圆心偏移不同（外 (12,12)、中 (11.2,12.4)、内 (12.6,11.6)），stroke-width 1.25，fill none，stroke currentColor。
- 24px 可读性：三圈间距 ≥2.5px，缩到 16px 仍能分辨三层；单色可用。

### 方案 B ——「两层错位平面」

- 概念名：错位平面
- 一句立意：两块相同形状的平面错位叠加，像设计稿与最终实现之间的那一层差距——最终落成的界面比设计稿多一层深度。
- SVG 规格：viewBox `0 0 24 24`，两个圆角矩形（rx 3）尺寸 14×14，第一块 (3,5)→(17,19)，第二块 (7,3)→(21,17)，fill none，stroke-width 1.5，第二块用 stroke-dasharray `2 2` 区分层次；或两块实心但第二块 opacity 0.55。
- 24px 可读性：错位量 4px，缩到 16px 仍可看出两层；单色可用。

### 方案 C ——「负空间切口」

- 概念名：切口
- 一句立意：一个实心块上切出一个「V」形负空间切口，像岛屿被海浪切开的峡湾，也像代码里的一段空白——留白本身就是设计。
- SVG 规格：viewBox `0 0 24 24`，外轮廓为 18×18 圆角方块 (rx 4) 占 (3,3)→(21,21)，中央切出一个 V 形负空间（points `12,7 16,17 8,17`），fill currentColor，fill-rule evenodd。
- 24px 可读性：切口宽度 ≥3px，缩到 16px V 形仍可辨；单色可用。

### 禁止

- 圆形/方形容器里塞一个汉字。
- 通用六边形。
- 渐变拟物。
- 字母 monogram。

### 落地

- `src/components/layout/Navigation.tsx:81-93` 的 `.brand__mark` 替换为内联 SVG（无容器背景），svg `width/height 24`，`aria-hidden`。
- favicon：把选定方案导出为 `public/favicon.svg`（viewBox 0 0 24 24）。
- 选定方案由 `default` 实施轮决定；本轮只给规格。

### morphicons 使用范围

仅在「图标 ↔ 图标」且结构匹配的场景使用 morphicons 的 `MorphIcon`：

- FAQ 的 chevron 下 ↔ 上（结构匹配：都是单 chevron，方向相反）。
- 不用于汉堡 ↔ X（3 线 vs 2 线，结构不匹配，硬用会抖）。
- 其他场景全部用 iconsax。

### 规格

- 网格 24×24；`reducedMotion="user"`；stroke 宽度随字号收缩（18px 图标 stroke 1.25，24px 图标 stroke 1.5）。
- 所有图标 `variant="Linear"`、`color="currentColor"`，不引入新颜色。
- `src/components/ui/SectionIcon.tsx` 已按此实现，无需改动；本节为规格确认。

## 四、文案（P1，官方、专业）

### 语气要求

官方、专业、克制。可以自信，但不卖萌、不用感叹号、不用「我们相信」类抒情句。

### 禁用词

全栈系 / 赋能 / 闭环 / 一站式 / 打造 / 极致 / 无缝 / 深耕 / 助力。

### 禁止中英混排

品牌名 YU STUDIO、技术专有名词除外。
