# 屿作所 — 综合数字产品工作室官网

Awwwards 获奖站风格，液态玻璃视觉，React 19 + TypeScript + Vite 5。

## 快速开始

```bash
npm install
npm run dev      # 开发
npm run build    # 构建 → dist/
npm run preview  # 预览构建产物
```

## 交付

- **构建产物**: `dist/` — 纯静态，可直接部署至 Vercel / Netlify / GitHub Pages
- **交付说明**: [HANDOFF.md](./HANDOFF.md)
- **QA 报告**: [QA-REPORT-t_7795889e.md](./dist/QA-REPORT-t_7795889e.md)
